# Client_System

순공 시간 조회, 구간 확인, 캘리브레이션을 하는 Android 네이티브 앱 (Java).

## 예정 화면

| 화면 | 내용 | 구분 |
|---|---|---|
| 로그인 | 토큰 발급 | 공통평가 01에서 가져옴 (별도 커밋) |
| 메인 | 오늘 순공 시간 (착석, 휴대폰, 졸음, 이탈 내역) | 신규 |
| 세션 목록 / 상세 | 목록 API, 획득 API, 구간별 근거 캡처 | 신규 (F1, F3) |
| 캘리브레이션 | 4단계 안내, 결과 임계값 표시 | 신규 (F2) |
