# SPEC

## 1. 정의

순공 시간 = 착석 시간 - 휴대폰 사용 시간 - 졸음 시간 - 자리 이탈 시간

- 착석 : 좌석 ROI 안에서 person이 검출된 상태
- 휴대폰 사용 : 착석 중 cell phone이 검출되고 그 위치가 움직이는 구간. 책상에 놓여만 있는 휴대폰은 차감하지 않는다
- 졸음 : 착석 중 엎드린 자세로 움직임이 없는 상태가 drowsy_sec 이상 이어진 구간
- 이탈 : ROI 안에 person이 없는 구간. away_sec 이상 지속되면 세션 종료

## 2. 자유 기능 (최대 3개)

| 번호 | 이름 | 해결하는 문제 | Edge | Service | Client |
|---|---|---|---|---|---|
| F1 | 순공 세션 측정 | 기본 시스템은 검출 순간마다 게시물만 쌓이고, 얼마나 앉아 있었는지는 알 수 없다 | ROI 착석 판정, 세션 분할 | 세션 모델, 목록/획득 API, 재계산 | 오늘 순공, 세션 목록/상세 |
| F2 | 휴대폰 거치/사용 구분 | 검출 여부만 쓰면 책상에 놓인 휴대폰도 사용으로 집계된다 | 이동량 계산, 상태 전이, 근거 캡처, 캘리브레이션 샘플 수집 | 구간 모델, 임계값 산출 | 구간 표시, 캘리브레이션 화면 |
| F3 | 졸음 판정 | 엎드려 자도 person이 검출되어 공부 시간으로 기록된다 | 자세 변화와 정지 판정, 근거 캡처 | 구간 종류 추가, 재계산 | 졸음 구간 표시 |

캘리브레이션은 F2와 같은 문제를 푸는 것이라 F2에 포함한다. 앱에서 구간을 교정해 임계값을 다시 맞추는 기능은 선택 사항으로 둔다.

## 3. 판정 (Edge)

### F1 착석과 세션

- person 박스 중심이 ROI 안이면 착석
- 이탈이 away_sec 미만이면 같은 세션으로 흡수, 이상이면 세션 종료
- 5초 미만 구간은 앞 구간에 병합

### F2 이동량

    이동량 = 최근 3초간 cell phone 박스 중심 변위 / 박스 대각선 길이

- 이동량 > phone_thr 이 2초 지속 : 사용 시작
- 이동량 <= phone_thr 이 5초 지속 : 거치로 복귀
- 구간 종료 시 근거 캡처 1장과 구간 최대 이동량(metric)을 함께 게시

캘리브레이션 (최초 1회, 단계당 10초, 각 단계 첫 1초는 버림)

| 단계 | 안내 | 얻는 값 |
|---|---|---|
| 1 | 평소처럼 앉기 | person 박스 중앙값으로 ROI 생성, 기준 박스 높이 h0 |
| 2 | 휴대폰을 책상에 두기 | m_still |
| 3 | 휴대폰을 들고 보기 | m_use |
| 4 | 자리 비우기 | 빈 좌석 확인 |

    phone_thr = ( max(m_still) + min(m_use) ) / 2

교정 (선택 사항)

- 오탐으로 교정된 구간의 metric 최대값 m_fp, 놓친 구간의 metric 최소값 m_fn
- m_fn 없음 : phone_thr = m_fp * 1.1
- m_fn 있음 : phone_thr = (m_fp + m_fn) / 2
- [0.1, 0.6]으로 제한, 교정 샘플 3개 미만이면 보정하지 않음, 보정마다 version 증가
- 앱은 metric이 임계값 근처인 구간만 확인 카드로 올린다. 무시하면 시스템 판정 유지

### F3 졸음

- 엎드림 : person 박스 높이 < 0.6 * h0 (h0는 캘리브레이션 1단계의 기준 높이)
- 정지 : 최근 10초간 박스 중심 변위 / 박스 대각선 < 0.05
- 엎드림과 정지가 함께 drowsy_sec(기본 180초) 이어지면, 조건이 시작된 시점부터 졸음 구간으로 기록
- 박스 높이가 0.8 * h0 이상으로 돌아오면 구간 종료
- 고개를 숙여 필기하는 자세는 높이 감소가 작고 움직임이 있어 해당하지 않는다
- 0.6, 0.05, 180초는 초기값이며 측정으로 조정한다

## 4. 데이터 모델 (Service)

| 모델 | 필드 |
|---|---|
| StudySession | author, started_at, ended_at, seated_sec, net_sec, config_ver |
| Segment | session, kind(phone/drowsy/away), started_at, ended_at, metric, evidence(Post), dismissed, corrected_at |
| DetectorConfig | author, version, roi, base_height, phone_thr, away_sec, drowsy_sec |

    net_sec = seated_sec - sum(dismissed가 아닌 구간 길이)

근거 캡처는 기존 Image Blog의 Post를 그대로 쓴다.

## 6. 검증

기준 측정 : ch08 기본 시스템(공통평가 02 코드)을 같은 자리에서 실행해 게시 건수와 오집계를 기록한다. 보고서의 "직접 관찰한 문제"와 각 기능의 "적용 전"에 쓴다.

| 번호 | 시나리오 | 기대 | 관련 |
|---|---|---|---|
| T1 | 10분 연속 착석, 휴대폰 없음 | 순공 10:00 | F1 |
| T2 | 착석 중 30초 이탈 | 같은 세션 유지 | F1 |
| T3 | 착석 중 3분 이탈 | 세션 2개 | F1 |
| T4 | 착석 5분 중 1분 휴대폰 사용 | 순공 4:00 | F2 |
| T5 | 휴대폰을 책상에 둔 채 5분 착석 | 순공 5:00, 차감 0 | F2 |
| T6 | T5 상태에서 2회 들었다 놓기 | 사용 구간 2개 | F2 |
| T7 | 고정 임계값과 캘리브레이션 임계값으로 T4~T6 반복 | 오차 감소 | F2 |
| T8 | 착석 중 5분 엎드림 | 순공에서 엎드린 시간 차감 | F3 |
| T9 | 고개를 숙여 5분 필기 | 차감 0 | F3 |

지표 : 순공 시간 오차(초, %), 휴대폰 사용 판정 Precision/Recall, 거치 오탐률, 필기 자세 오탐률.
직접 측정은 키 입력으로 구간 시작과 끝을 기록하는 스크립트로 한다.

## 7. 증빙 규칙 (보고서 양식 v2.0)
