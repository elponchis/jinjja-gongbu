# 진짜 공부해?

웹캠 기반 순공 시간 계측 서비스.
모바일/웹서비스 프로젝트 기말 과제.

## 무엇을 하는가

공부시간 앱은 시작과 끝 버튼을 누르는 자기신고 방식이라, 자리에 앉아 휴대폰을 본 시간도 공부 시간으로 기록된다.
이 서비스는 노트북 웹캠으로 착석, 휴대폰 사용, 졸음을 판정해 순수 공부 시간만 남긴다. 버튼은 누르지 않는다.

    순공 시간 = 착석 시간 - 휴대폰 사용 시간 - 졸음 시간 - 자리 이탈 시간

## 자유 기능

| 번호 | 이름 | 내용 |
|---|---|---|
| F1 | 순공 세션 측정 | 좌석 영역 안의 착석을 판정하고, 짧은 이탈은 흡수하며 세션 단위로 기록한다 |
| F2 | 휴대폰 거치/사용 구분 | 검출 박스의 이동량으로 책상에 놓인 휴대폰과 사용 중인 휴대폰을 구분한다. 임계값은 40초 캘리브레이션으로 정한다 |
| F3 | 졸음 판정 | 엎드린 채 움직임이 없는 구간을 졸음으로 판정해 공부 시간에서 뺀다 |

판정 수식, 데이터 모델, API는 docs/SPEC.md에 있다.

## 구성

| 폴더 | 역할 | 기술 |
|---|---|---|
| Edge_System | 웹캠 영상에서 착석, 휴대폰 사용, 졸음, 이탈을 판정하고 서버에 게시 | Python, YOLOv5, OpenCV |
| Service_System | 세션, 구간, 근거 캡처, 설정값을 보관하고 API로 제공 | Django, DRF, PythonAnywhere |
| Client_System | 순공 시간 조회, 구간 확인, 캘리브레이션 | Android (Java) |

    노트북 웹캠 -> Edge (판정) -> Service (보관, 제공) -> Client (조회, 설정)
                     ^                                      |
                     +---------- 설정, 임계값 --------------+

영상 원본은 Edge 밖으로 나가지 않는다. 서버로 가는 것은 판정 결과와 축소 캡처뿐이다.

## 환경변수

값은 저장소에 올리지 않는다. `.env.example`을 `.env`로 복사해 채운다.

| 이름 | 사용처 | 설명 |
|---|---|---|
| BLOG_HOST | Edge | 서버 주소 |
| BLOG_USERNAME | Edge | 게시용 계정 |
| BLOG_PASSWORD | Edge | 게시용 계정 비밀번호 |
| DJANGO_SECRET_KEY | Service | Django SECRET_KEY |
| DJANGO_DEBUG | Service | 개발 시 1 |
